Take your stories with you

Install Dream Media

Make Dream Media a standalone app on your desktop or home screen. The app keeps a local diary for offline use; signed-in users can optionally enable two-way syncing through Dream Media Cloud.

Checking installation availability…
Manual installation steps
  1. Windows / Mac: Open the hosted app in Chrome or Edge, then use the browser's Install app command (often in the address bar or menu).
  2. Android: Open the hosted app in Chrome, then use Install app or Add to Home screen from the browser menu.
  3. iPhone / iPad: Open the hosted app and choose Share → Add to Home Screen. iOS does not show this in-page Install button.

Installation requires HTTPS or localhost, not a file opened directly from your downloads. Once the app has loaded online, its interface and saved diary can work offline; catalogue searches, new covers and API results still require internet. Keep a JSON backup before moving to a new device or web address.
